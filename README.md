تطبيق ويب **مستقل بالكامل** لتعلّم الفرنسية بالعربية من المستوى **A0 إلى C1** — بنفس تقنية الملف المرجعي: مجلد واحد بملفات HTML/CSS/JS ثابتة، بلا تثبيت وبلا قواعد بيانات وبلا build.

## ▶️ التشغيل — اختر الطريقة الأسهل لك

### الطريقة 1: فتح مباشر (بلا أي متطلبات) ⭐
افتح الملف **`index.html`** بالنقر المزدوج — سيعمل التطبيق فوراً في متصفحك.
- كل شيء يعمل: الدروس، التمارين، المراجعة، التقدم محفوظ تلقائياً على جهازك.
- الفيديوهات التعليمية فقط تحتاج اتصال إنترنت (مدمجة من يوتيوب مع توثيق مصادرها).

### الطريقة 2: خادم محلي (يفتح التطبيق على هاتفك عبر الواي فاي) 📱
يتطلب [Node.js](https://nodejs.org) (مجاني):

| النظام | الطريقة |
|---|---|
| Windows | انقر مرتين على `start-windows.bat` |
| Mac | انقر مرتين على `start-mac-linux.command` |
| Linux | نفّذ: `bash start-mac-linux.sh` |

أو يدوياً: `node server.js` — سيفتح المتصفح تلقائياً ويعرض **رابط الهوت سبوت** (مثل `http://192.168.x.x:3000`) لفتحه من أي هاتف متصل بنفس الشبكة.

## 📱 تثبيته كتطبيق (PWA)
عند فتحه عبر الخادم (`http://localhost:3000`): استخدم زر «تثبيت التطبيق» في متصفحك (أو قائمة ← تثبيت / إضافة إلى الشاشة الرئيسية). بعد التثبيت يعمل بلا إنترنت بالكامل.

## 💾 أين يُحفظ تقدمي؟
تلقائياً في متصفحك (localStorage) — درجاتك، نقاط الخبرة، أيام التتابع، وبطاقات المراجعة.
للنسخ الاحتياطي أو النقل بين الأجهزة: **الإعدادات ← تصدير التقدم** ثم **استيراد** على الجهاز الآخر.

## 🗂 محتويات المجلد

| الملف / المجلد | الوظيفة |
|---|---|
| `index.html` | **افتح هذا الملف** — بوابة التطبيق |
| `js/data.js` | بيانات المنهج المدمجة (6 مستويات كاملة) |
| `js/app.js` | محرك التطبيق (راوتر، دروس، تمارين، مراجعة) |
| `css/styles.css` | التصميم (هوية زمردية + خطا Amiri وNoto Kufi) |
| `fonts/` | خطوط عربية مدمجة (تعمل دون إنترنت) |
| `icons/` | أيقونات التطبيق وPWA |
| `manifest.webmanifest` + `sw.js` | ملفات PWA (تثبيت + عمل دون إنترنت) |
| `server.js` | خادم محلي بلا اعتماديات + روابط الهوت سبوت |

## 📚 المنهج

- **A1 المبتدئ**: الحياة اليومية، التعريف بالذات، السوق، المطعم…
- **A2 الأولوي**: 6 مسارات (قراءة، قصص، قواعد، محادثة، استماع، تعبير)
- **B1 المتوسط**: 7 مسارات (تضاف الفرنسية المهنية 💼)
- **B2 المتقدم**: النقاش، المقالات، الأكاديمية والمهنية
- **C1 الإتقان**: الطلاقة، التحرير المتقدم، الفروق الدقيقة

الفيديوهات مدمجة من يوتيوب لأغراض التعلم، ومصادرها موثقة داخل كل درس (قسم «الواجب والمصادر»).

## ✏️ تعديل المحتوى
كل المحتوى في **`js/data.js`** بصيغة JavaScript واضحة (`window.FMA_DATA`): عدّل أي نص/سؤال/رابط فيديو بمحرر نصوص ثم احفظ — التغيير يظهر فوراً.
